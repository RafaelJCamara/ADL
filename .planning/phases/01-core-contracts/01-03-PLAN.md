<objective>
Land the architecture rules that keep every core contract pure and portable — before any adapter exists to break them — and prove each one fails on a deliberate violation.

Purpose: D-27's whole argument is that the dependency-graph rule arrives *with* the workspace rather than after the thing it would have prevented. 01-RESEARCH.md § Pitfall 8 names the failure mode precisely: a rule with no violation to catch is a rule nobody has seen work, so it ships mis-scoped and Phase 2 discovers it was decorative all along. The `@adl/core` purity ban is the same mechanism extended — 01-RESEARCH.md § Architectural Responsibility Map calls it out as a one-config-block cost now versus a Phase-5 refactor later. All six CORE contracts rest on `@adl/core` being pure and importable by third-party harness authors without dragging in a database driver or a filesystem dependency; this plan is what makes that structural.

Output: a flat ESLint config whose every architecture rule has been observed to fail, a toolchain assertion that catches the TypeScript-7 trap, and a CI workflow exercising both ends of the declared runtime range.
</objective>
