Make CORE-02's word *exhaustively* literally true, and make D-26's published JSON Schema an honest contract rather than a weaker shadow of the TypeScript one.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| third-party command gate → `.adl/verdicts/*.json` | A gate written in any language produces a payload ADL parses; the published schema is the only contract between them |
