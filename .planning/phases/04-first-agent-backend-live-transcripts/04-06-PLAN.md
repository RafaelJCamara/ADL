## Flagged assumption — BACK-05 edge probe row (unresolved)

The spec-less edge probe classified BACK-05 (*"Claude Code headless works as a backend"*) as
**`unclassified`**; its guidance is "review manually". An `unclassified` row is never auto-resolved
with a backstop marker, so it stays `unresolved` and is surfaced here rather than silently dropped.

**The specific ambiguity a reviewer should rule on:** BACK-05 says the backend *works*. Nothing in
REQUIREMENTS.md or CONTEXT.md states what "works" excludes at three boundaries this tracer meets:

- **Does "works" require a successful outcome, or a truthfully-reported one?** This plan's answer is
  the latter: an agent that runs, produces no commit, and says so honestly is a working backend
  reporting an unsuccessful run. That distinction is what prohibition P1 in this plan's `must_haves`
  makes checkable, and it is an implementation answer rather than a stated requirement.
- **Does "works" bind to a version range?** D-01 pins one exact version and D-02 hard-blocks
  anything else, so today the answer is "works at 2.1.237". `04-RESEARCH.md` records a near-daily
  release cadence, which means this requirement's truth has a shelf life nothing in the requirement
  itself acknowledges.
- **Does "works" survive the agent's own loop doing something ADL did not ask for** — writing
  outside the worktree, or installing a dependency? This plan's answer is that the workspace bounds
  it and the backend is not asked to; write auditing is Phase 15's WORK-08. Recorded so the gap is
  visible rather than assumed closed.

Recorded as an assumption, not a decision. Its first two halves are carried into `04-07`'s preflight
assertions and this plan's prohibition P1.
