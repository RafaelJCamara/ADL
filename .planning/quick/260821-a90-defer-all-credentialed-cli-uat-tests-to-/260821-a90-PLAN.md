agentic-CLI invocation (a live `ANTHROPIC_API_KEY` plus the pinned Claude Code CLI resolving
unshadowed on `PATH`, or the equivalent for a future backend) no longer gates the phase that
surfaced it. All such items accumulate across the project and run together in one
**end-of-project credentialed verification pass**.

EXECUTED-and-deferred — the same shape as the existing Phase 02 hold, for a different reason
(Phase 02 lacks a Linux *host*; Phase 04 lacks a *credential*).

and a COMPLETE checkbox is an environment precondition, not project work. Continuing to model
that as a blocker stalls the roadmap on setup. Batching also buys one honest reconciliation
window against real billed usage instead of many partial ones.

Output: Two edited planning documents. No source changes, no tests run, no ROADMAP edits.
